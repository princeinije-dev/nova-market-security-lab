# Nova Market

Nova Market is an AI-generated e-commerce platform created for learning and security testing.

This project demonstrates how AI-generated code can contain security weaknesses, even when an application appears to work correctly.

## About This Project

Nova Market was built using AI-assisted development.

The purpose of this project is to educate developers and the public about the importance of application security.

It shows why AI-generated code should always be reviewed, tested, and secured before being used in real-world applications.

## Security Testing

I, **Prince Inije**, conducted manual security testing on Nova Market to identify potential vulnerabilities.

During testing, I discovered security issues involving:

- Password reset token disclosure
- Unauthenticated access to customer orders

These findings are documented in [`security.md`](./security.md), along with the testing steps and screenshots.

## Project Purpose

This project was created to:

- Demonstrate real-world web application security testing.
- Understand how vulnerabilities occur in AI-generated code.
- Practice identifying and documenting security issues.
- Educate developers about secure coding practices.
- Encourage security testing before deploying applications.

## Disclaimer

Nova Market is a learning and security research project.

The application is not intended for production use in its current state.

All testing was performed in a local development environment.
